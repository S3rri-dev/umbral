# Preferencias locales

Umbral usa el dominio de UserDefaults `io.github.s3rri-dev.umbral`. La aplicación guarda archivos propios en `~/Library/Application Support/io.github.s3rri-dev.umbral`. El color de acento conserva su clave de la versión anterior y el tema se recupera si la configuración de 2.0.0 aún está vacía.

El catálogo de 2.0.0 se configura en la bienvenida y en Ajustes. Los archivos que elijas exportar permanecen en el destino que indiques.
