# Alcance de Umbral 2.0.0

La bienvenida y **Ajustes → Funciones** ofrecen estas 43 herramientas. Algunas dependen de la versión de macOS, el hardware o los permisos concedidos.

| Grupo | Herramientas |
| --- | --- |
| Ventanas y Dock | Selector, vista previa del Dock, clics en el Dock, maximización, disposición y salir al cerrar |
| Ratón y teclado | Desplazamiento invertido |
| Portapapeles y archivos | Historial, pegar sin formato y bandeja |
| Audio | Mezclador, selector de salida, prioridad de dispositivos y silencio del micrófono |
| Energía | Mantener despierto |
| Utilidades | Panel rápido, selector de color, modo limpieza, multimedia, limpiador, cámara y grabador |
| Dynamic Island | Isla, calendario, notificaciones, gestos, temporizador, accesorios, letras, cola, ecualizador, descargas, agentes, vigilancia y mascota |
| Monitor | CPU, GPU, memoria, red, disco, energía, dispositivos y ventiladores |

El DMG local usa firma ad hoc. Ventiladores ofrece lectura de sensores compatibles. El control manual y las curvas requieren la firma del asistente. El grabador exporta archivos locales. Los enlaces temporales requieren un servicio de alojamiento de Umbral.
