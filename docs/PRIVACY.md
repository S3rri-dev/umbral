# Privacidad

Umbral guarda preferencias y datos de herramientas en el Mac. Las grabaciones se exportan a archivos. El historial del portapapeles y las integraciones de Dynamic Island se gestionan desde sus propios controles.

Las consultas de letras, precios de modelos, actualizaciones y medición de velocidad pueden usar la red al activar sus opciones. Los proveedores reciben los datos necesarios para la consulta correspondiente. Consulta [Permisos](PERMISSIONS.md) y [Preferencias locales](DATA.md).
