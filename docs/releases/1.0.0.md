## Umbral 1.0.0

Primera edición pública del catálogo de utilidades para macOS. Incluye bienvenida, búsqueda, biblioteca, ajustes de tema y acento y acceso desde la barra de menús con el símbolo Fuga.

Las fichas de cierre, maximización y mezclador de audio aparecen **en preparación**.

### Descarga

- **DMG ARM64** para arrastrar Umbral a Aplicaciones.
- **ZIP ARM64** con la misma app.
- **ZIP de fuentes**, manifiesto y sumas **SHA-256**.

Compilada para Apple Silicon con macOS 14 como objetivo mínimo. La app lleva **firma ad hoc**, sin Developer ID ni notarización. [Instalación](https://github.com/S3rri-dev/umbral/blob/v1.0.0/docs/INSTALL.md) · [Verificación](https://github.com/S3rri-dev/umbral/blob/v1.0.0/docs/VERIFICATION.md)
