# Permisos

La bienvenida muestra los permisos de las herramientas elegidas. Puedes consultarlos más tarde en **Ajustes → Funciones**. La mayoría se solicitan cuando activas una herramienta que los necesita.

| Permiso | Ejemplos de uso |
| --- | --- |
| Accesibilidad | Ventanas y Dock, atajos, observación de notificaciones y modos de entrada |
| Grabación de pantalla | Miniaturas, grabador y vigilancia de regiones |
| Audio del sistema | Mezclador, ecualizador y grabación con audio |
| Cámara y micrófono | Vista previa de cámara y grabación con el micrófono elegido |
| Calendario, Bluetooth y automatización | Eventos, baterías de periféricos y reproducción multimedia |
| Archivos y carpetas | Bandeja, descargas, herramientas multimedia y limpieza de elementos seleccionados |

Mantener despierto con la tapa cerrada tiene un paso de autorización de administrador. Los controles de ventilación que escriben en el hardware necesitan un asistente con firma de distribución.
