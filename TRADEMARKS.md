# Nombre e identidad

**Umbral** y el símbolo **Fuga** identifican este proyecto. Puedes usar el nombre para describir, citar o enlazar Umbral. Identifica las versiones modificadas con nombre e icono propios para evitar que se confundan con las del mantenedor.

La licencia GPL-3.0-or-later se aplica al código. El nombre, los iconos de marca y las imágenes promocionales se conservan como identidad del proyecto. El documento no declara un registro de marca.
