# Contribuir a Umbral

Abre una propuesta antes de cambiar la arquitectura, añadir permisos o implementar una herramienta que modifique macOS. Describe el problema que resolvería y cómo probarías el comportamiento.

Para cambios concretos, trabaja en una rama y sigue [Verificar Umbral](.agents/skills/verificar-umbral/SKILL.md). En Codex puedes invocar `$verificar-umbral` desde este repositorio. La guía enlaza el script que usa el CI y explica cómo preparar una copia aislada para las pruebas nativas. Incluye los resultados en el pull request.

Las contribuciones al código se publican bajo GPL-3.0-or-later.
