# Contribuir a Umbral

Abre una propuesta antes de cambiar la arquitectura, añadir permisos o implementar una herramienta que modifique macOS. Describe el problema que resolvería y cómo probarías el comportamiento.

Para cambios concretos, crea una rama, ejecuta `./tests/run.sh` y comprueba la interfaz si la has tocado. Incluye los pasos de verificación en el pull request. Las contribuciones al código se publican bajo GPL-3.0-or-later.
