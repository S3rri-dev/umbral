# Código de conducta

Trata a las personas con respeto. Discute el cambio y aporta contexto para reproducirlo. Evita el acoso, los ataques personales y la publicación de datos de otras personas.

Si necesitas informar de un problema de conducta, contacta con el mantenedor mediante un canal privado de GitHub. Las incidencias técnicas ordinarias tienen sus propias plantillas.
